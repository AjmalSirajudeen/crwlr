# Project Brief: CRWLR

## Overview
CRWLR is a social venue discovery platform that helps users explore and organize bar crawls with friends. The application combines social networking with venue discovery to create engaging nightlife experiences.

## Core Features
- Venue discovery with filtering and search
- Bar crawl creation and management
- Real-time check-ins and social interactions
- Points-based gamification system
- Social features including friend connections
- Leaderboard and achievements system

## Goals
1. Simplify nightlife planning and coordination
2. Create engaging social experiences
3. Encourage venue exploration
4. Build community through shared experiences
5. Provide value to both users and venues
